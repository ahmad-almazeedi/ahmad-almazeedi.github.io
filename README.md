# ahmad-almazeedi.github.io

Source for my personal page, published with GitHub Pages: useful and beautiful software, made for everyone.

Every product on the page can be tried right there: a working Haseba calculator, the Animath step-by-step solver, the iLostCount counter, and an Atmita demo. The page works in English and Arabic (`?lang=ar`), light and dark, by keyboard and screen reader, with no trackers.

- [Atmita](https://atmita.com/): personal AI agent
- [Haseba](https://apps.apple.com/us/app/haseba-calculator-converter/id1121281655): iOS calculator
- [Animath](https://apps.apple.com/us/app/animath-ai-tutor-solver/id1615638274): step-by-step algebra, solver engine at [AnimathSolver](https://github.com/ahmad-almazeedi/AnimathSolver)
- [iLostCount](https://ilostcount.com/): browser text counter for characters, words, LLM tokens and speaking time
